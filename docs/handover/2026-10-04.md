## How we ship (unchanged)

1. Work on a branch in a worktree under `~/Github/_scratch-berth/<name>`.
2. Run the reviews: Opus lenses, plus a delta verifier when blockers or majors were fixed.
3. Merge `origin/master` into the branch, then run `pnpm exec tsc --noEmit`, `pnpm lint` and `pnpm test` (no args after `--`).
4. If the branch adds schema, run `pnpm db:push`. A worktree has no `.env.local`, so symlink the main checkout's file first, then remove it. **The 4 Oct ship missed this once.**
5. Squash-ship:
   - `git worktree add --detach ../ship origin/master`
   - `git merge --squash <branch>`
   - `git -c commit.gpgsign=false commit`: always unsigned, because gpg has no pinentry.
   - `git push origin HEAD:master`
   - Remove the ship worktree.
6. Write the commit message in the Berth register: one plain sentence, harbour imagery allowed.
