# No leaderboard

The obvious gamification move for an XP system, and explicitly not wanted
(David, 2026-08-07): LSTeaTime celebrates like a tea house, not a casino, and
a leaderboard turns rank into competition between strangers. This decision
also keeps the XP economy low-stakes — rank tiers stay uncapped and referral
XP needs no tight anti-abuse budget precisely because nobody can win anything
by farming it. Revisit only at David's initiative; reviews and feature rounds
should not re-propose it.
